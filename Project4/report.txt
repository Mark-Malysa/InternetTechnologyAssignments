Part B: Wireshark/TShark Instructions (guided by your sample run)
-----------------------------------------------------------------
Use the actual destination IP you saw in your trace. From your ilab run:
- Destination hostname: www.princeton.edu
- Destination IP observed: 104.18.5.101 (Cloudflare front-end for Princeton)

Capture steps (Wireshark GUI):
1) Start Wireshark on the ilab machine. Pick the interface that has internet access (often `eth0` on ilab; if unsure, look for the one with increasing packet counters).
2) Set a display filter to see only relevant traffic:  
   `icmp or ip.addr == 104.18.5.101`  
   (If your trace shows a different destination IP, replace 104.18.5.101 with that IP. Using the literal IP avoids name-resolution mismatches.)
3) Click Start (blue fin icon) to begin capturing **before** running traceroute.
4) In a terminal, run:  
   `python3 traceroute_skeleton.py`
   - This uses `IP_RECVERR`, which works only on Linux (ilab/WSL/Ubuntu). It will not work on macOS natively.
5) Wait for traceroute to finish (you saw destination at hop 12 in your sample).
6) Stop the capture (red square).
7) Save the capture as `traceroute.pcapng`.

Optional TShark (CLI) capture instead of GUI:
```
sudo tshark -i eth0 -f "icmp or host 104.18.5.101" -w traceroute.pcapng
```
Replace `eth0` if your interface differs; replace the host IP if your destination IP differs.

How to find packets for the questions:
- First request packet: look for the first UDP probe you sent (TTL=1). It will have src IP = your ilab host, dst IP = 104.18.5.101, protocol = UDP.
- First router response: the matching ICMP Time Exceeded (Type 11, Code 0) coming back from hop 1 (in your run: `128.6.13.1`).
- Destination response: the ICMP Destination Unreachable, Port Unreachable (Type 3, Code 3) from the destination IP (104.18.5.101) at the hop where you reached it (hop 12 in your sample).
- Counting routers: count the distinct hops before the destination line in your traceroute output (you saw 11 routers; destination on hop 12).
- TTL at destination: the hop number where the destination replied (12 in your sample).
