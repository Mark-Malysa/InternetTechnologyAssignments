Project 4 Report
================

Part B: Wireshark/TShark Instructions
-------------------------------------
1. Install Wireshark or TShark if not already installed.
2. Open Wireshark.
3. Select the network interface you are using to connect to the internet (e.g., eth0, wlan0, en0).
4. In the filter bar, enter the following filter to capture only relevant traffic:
   icmp || ip.addr == <destination_ip>
   
   (Replace <destination_ip> with the resolved IP of www.princeton.edu or your target. You can find this by running `ping www.princeton.edu` or looking at the traceroute output)
   
5. Start the capture (Blue fin icon).
6. Run your traceroute program:
   python3 traceroute_skeleton.py
   
   **IMPORTANT**: The provided implementation uses `IP_RECVERR` which is a Linux-specific socket option. You must run this code on a Linux machine (e.g., an Ubuntu VM, WSL, or an ilab machine). It will NOT work correctly on macOS or Windows natively.
   
7. Wait for the traceroute to complete.
8. Stop the capture (Red square icon).
9. Save the capture file (File > Save As) as 'traceroute.pcapng'.

To analyze the capture for the questions:
- Locate the first UDP packet sent by your computer. This is the first probe (TTL=1).
- Locate the corresponding ICMP response (Type 11: Time-to-live exceeded) from the first router.
- Use these packets to answer the questions about IP headers, ICMP types/codes, etc.
